# 年谱

> [!note] 李德年谱
> 2月初第1师到达郴州良田，在大福桥与国民党军第35军的六个连交战，朱德指挥部队智取，敌军官兵全被俘虏。郴州城内守敌闻风而逃，起义部队不战而胜，进驻郴州。
> 2月中下旬 国民党新军阀李宗仁 与唐生智 交战，湘南敌军少，地方团练又无战斗力，所以宜章、郴州战后，朱德分兵资兴、永兴、耒阳、汝城、安仁等县开展群众工作，建立苏维埃政府，组织农民武装。
> 2月26日 国民党桂系第19军李宜煊师直扑耒阳，林彪率一个连阻击敌一个营，掩护大部队撤退。接着又配合大部队对占领耒阳的敌军实行反包围。
